# Proyecto Final MLOps: Predicción de Churn en Telecomunicaciones

## Descripción del Proyecto Este proyecto 
Este proyecto implementa un flujo completo de Machine Learning (MLOps) para predecir la fuga de clientes (Churn) utilizando un dataset de telecomunicaciones de 10,000 registros

## Estructura del Repositorio
- `data/`: Contiene el dataset fuente `telecom_churn_10000.csv`.
- `notebooks/`: Cuadernos con el Análisis Exploratorio de Datos (EDA) y entrenamiento.
- `app.py`: API REST desarrollada en FastAPI para el consumo del modelo en producción.
- `requirements.txt`: Dependencias del proyecto.
